# V1.4.3 Automatic Codes Report

## Implemented
Automatic code generation now applies to every existing core entity that already has a code field: Students, Batches, Subjects, Terms/Semesters, and Course Offerings.

Manual entry remains supported. Blank code fields mean “generate automatically”. Generated values are based on the persisted internal record ID and use fixed prefixes.

## Formats
| Entity | Format | Example |
|---|---|---|
| Student | STU-###### | STU-000123 |
| Batch | BAT-###### | BAT-000004 |
| Subject | SUB-###### | SUB-000018 |
| Term | TRM-###### | TRM-000007 |
| Course Offering | OFF-###### | OFF-000052 |

## Compatibility
No table or column was added/removed. Existing user-entered codes are retained. No D1 migration is necessary from V1.4.2.
