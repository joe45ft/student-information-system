# V1.4.8 Keep Owner Reset Report

The previous V1.4.7 factory reset deleted every user and returned the installation to First Setup. V1.4.8 changes the destructive action to match the requested operating model: clear the application while preserving the current Owner.

## Preserved
- Current OWNER user row and password hash
- OWNER role and active status
- Current authenticated session only
- D1 tables, indexes, schema version, and migration metadata

## Deleted / Reset
- Students and all academic network data
- Batches, groups, lecturers, subjects, terms, offerings, enrollments
- Every other user and all their sessions
- Other Owner sessions
- User permission overrides
- Activity logs, login attempts, password reset requests
- Organization settings (then recreated with defaults)

## Safety
The action is OWNER-only and requires the current password, exact confirmation phrase, acknowledgement checkbox, CSRF validation, and final confirmation.
