# V1.4.7 Factory Reset Report

## Implemented
A guarded, system-wide data reset was added to Settings. It is intentionally stronger than per-record Custom Delete and is designed for administrators who want to return the application to a clean first-run state without deleting or recreating the Cloudflare D1 database itself.

## Safety controls
- Only an authenticated `OWNER` can open or submit the factory reset.
- Current Owner password must verify successfully.
- Exact phrase `DELETE ALL DATA` is required.
- Explicit acknowledgement checkbox is required.
- The UI presents a final browser confirmation.
- Current record counts are shown before reset.

## Deleted data
Students, enrollments, course offerings, terms, subjects, lecturers, groups, batches, password reset requests, sessions, permission overrides, activity logs, login attempts, settings, and all users.

## Preserved technical structure
- D1 database itself
- Tables and indexes
- `app_meta.schema_version`
- Schema version remains 4

After reset, default organization settings are recreated and the user is redirected to `/setup` to create a new Owner.

## Database migration
None.
