# V1.4.6 Custom Delete Report

Custom Delete was added as a controlled deletion workflow rather than a force-delete feature. It covers Students, Batches, Groups, Lecturers, Subjects, Terms/Semesters, and Course Offerings. The screen previews dependencies and active blockers, offers Deactivate/Close when safe, and permits permanent deletion only for isolated records. A permanent action requires typed confirmation, acknowledgement, and an audit reason. This preserves enrollment and academic history and avoids accidental cascading data loss.

Database schema: unchanged (V4).
Runtime dependencies: unchanged (zero).
